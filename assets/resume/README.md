# Resume

Professional resume and CV documents for download.

## 📁 Contents

```
resume/
├── resume.pdf                          # Main resume (PDF format)
├── resume.docx                         # Editable resume (Word format)
├── CV.pdf                              # Detailed CV (PDF format)
├── coverLetter.txt                     # Cover letter template
└── README.md                            # This file
```

## 📄 Document Types

### Main Resume - resume.pdf

**Purpose**: Standard resume for most applications

**Format**: PDF (universal compatibility)

**Specifications**:

- **Length**: 1-2 pages (typically 1)
- **Format**: PDF for ATS compatibility
- **File Size**: < 1 MB
- **Fonts**: Professional (Arial, Calibri, Helvetica)

**Usage**:

- Primary resume for job applications
- Job boards and ATS systems
- Email attachment
- Portfolio website download link

## 💾 Setup Instructions

### Initial Setup

1. **Place resume files** in this folder:
    - `resume.pdf` - Primary resume
    - `resume.docx` - Editable template
    - `CV.pdf` - Comprehensive CV

2. **Verify file naming** (case-sensitive for GitHub Pages):
    - ✅ `resume.pdf`
    - ❌ `Resume.pdf` (wrong case)

3. **Test download link**:
    - Build: `npm run build`
    - Check `dist/assets/resume/`
    - Test in deployed site

### File Size Recommendations

| File        | Max Size | Recommended |
|-------------|----------|-------------|
| resume.pdf  | 5 MB     | < 1 MB      |
| resume.docx | 3 MB     | < 500 KB    |
| CV.pdf      | 5 MB     | < 2 MB      |

## 📋 Best Practices

### Professional Summary

- 2-3 sentences of key qualifications
- Quantify achievements
- Action-oriented language
- ATS-friendly format

### Experience Bullets

```
Senior Engineer | Company | Jan 2022 - Present
• Led ML system increasing engagement by 40%
• Designed microservices using Docker/Kubernetes
• Mentored 3 developers, improving productivity 25%
```

### Skills Section

```
Technical Skills:
• Languages: Python, JavaScript, Java, SQL
• Frameworks: React, Django, PyTorch
• Tools: Git, Docker, Kubernetes, AWS
```
